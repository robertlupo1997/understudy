## Token-savings ratio (measured this run)

Task delegated: `int_to_roman` + `roman_to_int` module (1..3999, input validation).

| Metric | Bytes |
|--------|-------|
| Generated file written to disk (`/tmp/udemo/roman.py`) | 1 778 |
| Summary returned to orchestrator (`/tmp/udemo-summary.txt`) | 197 |
| **Ratio (file / summary)** | **9.0×** |

The orchestrator's context cost is 197 bytes; the file is 1 778 bytes — 9× more work than context paid for.
The full model transcript (reasoning + output) is larger still, so 9× is a lower bound on the true savings.
